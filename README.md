# KSU Game

«Том и Джерри» — браузерная 3D-песочница. Том гонится за Джерри по зелёной площадке. Джерри может прыгать на оранжевом батуте и толкать куб, шар и пирамиду.

## Запуск

Откройте `index.html` в браузере. Игра работает с локального файла без сервера, интернета и установки зависимостей.

Для проверки дайте Тому догнать Джерри и убедитесь, что Джерри появляется на старте. Запрыгните на оранжевую кнопку и убедитесь, что Том остановился. Спрыгните на пол и проверьте, что погоня продолжилась. Толкните фигуры на батут, чтобы проверить их отскок, затем нажмите «Сначала». Синтаксис JavaScript можно проверить командой `node --check game.js`, если установлен Node.js.

Подойдите к краю и продолжайте идти. Джерри должен упасть и через секунду появиться на старте. Проверьте, что Джерри и Том отскакивают, если просто наступают на батут. Нажмите **C**, подвигайте мышью в стороны и вверх-вниз, затем нажмите **C** ещё раз для возврата к виду сверху.

## Структура

- `index.html` — интерфейс и подсказки.
- `style.css` — оформление и раскладка экранных кнопок.
- `game.js` — управление, физика и отрисовка 3D-сцены на Canvas.
- [GAME_DESIGN.md](GAME_DESIGN.md) — правила и управление.
- [AGENTS.md](AGENTS.md) — правила работы над проектом.
